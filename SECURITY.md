# Security

Please don't report security problems in public issues. Use GitHub's private vulnerability reporting instead: **Security → Report a vulnerability** on this repository.

Say what you found, how to reproduce it, and what it lets someone do. You'll hear back as soon as possible. Please give us a chance to fix it before you tell anyone else.

Only the code in this repository and the site at grimwilder.com are in scope. Please don't test against other people's accounts or campaigns, and don't run load or denial-of-service tests.
